# ariseOS informational site

`index.html`, `app.js` and `styles.css` provide the static informational site.
They do not install the server or validate its integrations.

Use the repository's [README](../README.md), [installation guide](../INSTALL.md)
and [ISO build guide](../installer/MAKE-USB.md) for current setup instructions.
Use [ANSWERS.md](../docs/ANSWERS.md) for the owner's current decisions and
[INDEPENDENT-REVIEW.md](../docs/INDEPENDENT-REVIEW.md) for validation limits.

The earlier duplicate installation cookbook was removed because it disagreed
with the current branch, credential locations, backup retention and timer policy.
